# LOW TIDE

First-person single-player narrative exploration RPG on an isolated island. An anomalous tide exposes valuable salvage, forgotten structures, story evidence and dangerous phenomena. No traditional combat.

Loop: mission → prepare → low tide → explore → collect loot/evidence → manage time/risk → return → sell/keep/craft → relationships/story → deeper expeditions.

Priorities: atmosphere, exploration, meaningful loot, crafting, trading/economy, mystery/narrative, risk/reward (in this order).

Full-game target, not pilot scope: 2–4 hours; one compact island and settlement; 5–6 major areas, about 3 low-tide areas; 10–12 significant NPCs; main missions and side quests. Procedural variation in loot/events, not world generation.

Pilot: EUR 0 purchases, paid APIs or servers; offline Windows. Agents own technical production; Director makes creative decisions and reviews builds. Deliver M0.5 first, then extend the same project into an 8–12 minute vertical slice.
